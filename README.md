# Playwright - First Automated Test

Projeto introdutório de automação de testes realizado durante meus estudos de Quality Assurance na Mate Academy.

## Objetivo

Praticar a configuração do ambiente de automação, a instalação do Playwright e a execução de um primeiro teste automatizado.

## Ferramentas utilizadas

* Visual Studio Code
* JavaScript
* Node.js
* Playwright
* GitHub

## Atividade prática

* Clonagem do repositório de exemplo.
* Instalação das dependências com `npm i`.
* Instalação do Playwright.
* Execução de testes utilizando o Playwright UI.
* Registro da execução em documento de evidências.
